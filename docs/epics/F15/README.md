# F15 · Configurable Workspace

Que cada organización (sobre todo el cobrador independiente) oculte los módulos, secciones y campos que no usa, sin tocar datos, permisos ni topes del plan. Regla de fondo: `visible = plan ∧ permiso ∧ workspace`; el workspace solo **quita** y la API no lo consulta (ocultar ≠ autorizar).
