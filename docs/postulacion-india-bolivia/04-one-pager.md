# Kobrax — resumen de una hoja

**De gestionar cobranzas a mejorar las decisiones de recuperación.**

| | |
|---|---|
| **Problema** | Cobradores, cooperativas y financieras pequeñas de Bolivia cobran con papel, Excel y WhatsApp: sin ruta, sin visibilidad, sin prueba de la visita y sin saber qué estrategia funciona. Los sistemas institucionales existen, pero son costosos o solo registran. |
| **Solución hoy** | App móvil offline para el cobrador + panel web para el supervisor + API segura. Importa la cartera, ordena la ruta y registra cada visita con foto, GPS y huella SHA-256, con promesas y resultados estructurados. |
| **Siguiente etapa** | Usar esos datos para asistir decisiones: resumir historiales, señalar promesas incumplidas y, con datos suficientes, medir qué estrategias recuperan mejor. **Aún no implementado.** |
| **Para quién** | Cobrador independiente (plan gratuito) · agencias · cooperativas · financieras. |
| **Estado** | MVP funcional: 20 módulos de backend, panel web de ~25 pantallas, app móvil de 5 pestañas; 916 pruebas móvil y 1.542 API verdes. Desplegado en https://kobrax.ikigaisystems.lat con datos de prueba; piloto con usuarios reales: siguiente paso. |
| **Diferenciadores** | Evidencia inalterable · mismo producto del independiente al banco · aislamiento por cliente en la base de datos · mora modelada como episodios (datos listos para analizar). Offline y rutas también los ofrecen otros: no son el diferencial. |
| **Modelo** | FREE $0 · PROFESSIONAL $12/cobrador · BUSINESS $99 + $10/cobrador · ENTERPRISE desde $800 + $8/cobrador. |
| **Impacto** | Inclusión: herramientas profesionales al prestamista pequeño. Ambiental: menos papel y rutas más cortas (medición propuesta en piloto). |
| **Expansión** | Región andina; conexión con la India como exploración en microcrédito de campo y pagos interoperables. |
