# Kobrax — resumen de una hoja

**Cobranza con evidencia, desde el celular, incluso sin internet.**

| | |
|---|---|
| **Problema** | Cobradores, cooperativas y financieras pequeñas de Bolivia cobran con papel, Excel y WhatsApp: sin ruta, sin visibilidad y sin prueba de la visita. |
| **Solución** | App móvil offline para el cobrador + panel web para el supervisor + API segura. Importa la cartera, ordena la ruta y registra cada visita con foto, GPS y huella SHA-256. |
| **Para quién** | Cobrador independiente (plan gratuito) · agencias · cooperativas · financieras. |
| **Estado** | MVP funcional: 20 módulos de backend, panel web de ~25 pantallas, app móvil de 5 pestañas, 750 pruebas verdes en móvil. Desplegado en https://kobrax.ikigaisystems.lat con datos de prueba; piloto con usuarios reales: siguiente paso. |
| **Diferenciadores** | Evidencia inalterable · offline-first · mismo producto del independiente al banco · aislamiento por cliente en la base de datos · rutas con motor propio. |
| **Modelo** | FREE $0 · PROFESSIONAL $12/cobrador · BUSINESS $99 + $10/cobrador · ENTERPRISE desde $800 + $8/cobrador. |
| **Impacto** | Inclusión: herramientas profesionales al prestamista pequeño. Ambiental: menos papel y rutas más cortas (medición propuesta en piloto). |
| **Expansión** | Región andina; conexión con la India como exploración en microcrédito de campo y pagos interoperables. |
